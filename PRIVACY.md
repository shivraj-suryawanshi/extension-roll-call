# Privacy policy for Extension Roll Call

Last updated: 12 November 2026

Extension Roll Call does not collect, send, sell or share any data.

## What the extension reads

When you open it, the extension asks the browser for the list of installed extensions, themes and apps: their names, versions, permissions, the websites they can run on, and how they were installed. It uses this list only to build the report you see on screen.

## What stays on your computer

- The report is built in your browser. No part of it is sent to me or to anyone else.
- The extension makes no network requests and contains no analytics, advertising or tracking code.
- If you type an audit label, it is saved in the browser's local storage on your device so it is still there next time. Removing the extension removes it.
- CSV, JSON and PDF files are created only when you click an export button, and are saved wherever you choose.

## Permission used

`management`: needed to read the list of installed extensions and to switch an extension on or off when you click the button for it.

## Changes

If this policy changes, the new version will be published at the same address with a new date.

## Contact

Questions about this policy can be raised through the issues page of the project's GitHub repository.
